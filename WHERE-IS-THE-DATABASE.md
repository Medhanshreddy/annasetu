# Where data lives

## Inside the phone (default)
The APK stores users, slots, tokens, OTP, payments, tickets in the phone:
`localStorage` key `annasetu_db_v3`.
No paid SMS. No internet required for login / OTP / booking.

OTP is a 6-digit code generated by OUR code on the device, saved 5 minutes, shown on screen and in SMS outbox.

## On the laptop (optional)
`node server.js` uses SQLite (`annasetu.db`).
Use this only if you type a Laptop URL in the login box.
Leave that box EMPTY on the phone so the on-device database is used.
